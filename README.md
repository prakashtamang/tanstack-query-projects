# Learning TanStack Learning Projects

A hands-on learning repository for understanding **TanStack Query (React Query)** by building progressively more advanced projects.

Instead of learning TanStack Query only through theory, this repository focuses on applying each concept in a practical project and gradually building up from basic queries to mutations, caching, optimistic updates, pagination, infinite queries, and dependent queries.

## Why Project-Based Learning?

TanStack Query provides many APIs and concepts that can be difficult to understand in isolation.

Each project in this repository introduces a new layer of complexity:

**Project 1** → Learn how queries and caching work.

**Project 2** → Learn how mutations interact with cached server state.

**Project 3** → Learn how to handle more advanced data-fetching patterns.

This progression is designed to make each new concept build upon the previous one.
