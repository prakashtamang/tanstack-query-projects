# Blog / Infinite Feed

A React blog and infinite feed application built to practice advanced TanStack Query concepts. The project demonstrates normal pagination, page-based query keys, infinite queries, prefetching, and dependent queries using a real REST API.

The UI is styled with Tailwind CSS.

## Features

- Normal pagination
- Page-based query keys
- Infinite queries with useInfiniteQuery
- Load more posts with fetchNextPage
- Detect additional pages with hasNextPage
- Loading states
- Error handling
- Prefetching upcoming pages
- Dependent queries using enabled
- API data fetching with fetch
- Reusable Post Card components
- Responsive UI with Tailwind CSS
- TanStack Query caching and query management
