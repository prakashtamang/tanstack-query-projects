# Product Explorer

A React product explorer built to learn and practice the core concepts of **TanStack Query**.

This project focuses on fetching, caching, refetching, conditional queries, and prefetching server state using TanStack Query

## Features

- Fetch products from Fake Store API
- View product details
- Cached product data
- Manual refetching
- Loading states
- Error handling
- Conditional queries with enabled
- Product-detail prefetching on hover
- Query caching
- Configurable staleTime
- Configurable gcTime
- Background fetching indicator
- Responsive UI
- Tailwind CSS styling
